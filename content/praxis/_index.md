Use Praxis’s built-in filters to choose where requests go, change headers, and apply security checks. Filter settings live in YAML; running Praxis requires a Rust build or a supplied Praxis binary. [Choose and configure built-in filters]({{< relref "guides/use-filters.md" >}}) or start with {{< docs-link product="praxis" source="docs/quickstart.md" label="the quickstart" >}}.

Developers who need new behavior can follow {{< docs-link product="praxis" source="docs/filters/http-filter-tutorial.md" label="the custom HTTP filter tutorial" >}}.
